Ways to add videos

Bookmarklet (PC): drag this to your bookmarks bar, then click it on any YouTube video page:
Dub this

Command line: uv run yt-jp-redub add <url>

Phone: open in Firefox on the same Wi-Fi and paste a link, or share links to the Telegram bot if you set one up.

asbplayer (PC): enable its WebSocket client in asbplayer's settings (Misc) with . Subtitles load automatically once they're complete.
